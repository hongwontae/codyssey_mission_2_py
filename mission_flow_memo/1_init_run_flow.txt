1. main 파일 실행

2. QuizGame 클래스 호출
    2-1. self.quizzes -> 해당 객체의 퀴즈 목록
    2-2. self.best_score -> 최고 점수를 저장
    2-3. self.history -> 퀴즈 기록을 저장하는 리스트
    2-4. self.load.state()
        1. 해당 함수를 호출해서 시작하자마자 state.json 파일에 데이터를 가져옵니다.

        2. 이 떄 with open을 통해서 파일을 가져오고 json.load()를 통해 json 문자열을 python 객체로 가져옵니다.

        3. 전달된 data["quizzes"]는 다양한 작업을 위해서 for + Quiz를 통해 하나씩 객체로 만듭니다.
            => 가져온 json 파일의 quizzes의 형태는 리스트에 객체가 있는 형태입니다. -> 그 객체를 통해서 Quiz 클래스로 초기화해야함
            => 그래서 하나씩 가져와서 key_value 접근으로 객체를 생성하고 append합니다.

        4. 만약 try 시도 중 파일을 찾을 수 없는 에러가 발생 -> FileNotFoundError -> except이 잡습니다.

        5. 만약 try 시도 중 JSON 형식이 올바르지 않을 때 발생하는 예외 -> json.JSONDecodeError -> except이 잡습니다.
            5-1. json 파일에 중괄호 하나가 없거나 구조를 갖추지 않은채 텍스트만 적혀있다면 -> json.JSONDecodeError

        6. 만약 에러가 발생해서 except이 실행
            6-1. self.init_quizzes()이 실행됩니다.
                => load_state()에 저장된 파일에서 JSON 문자열을 가져와서 Quiz 객체로 만들어야 할 작업을 할 수 없으니
                => 기존에 하드코딩된 문자열을 통해서 Quiz 객체로 만듭니다.
            6-2. 그 다음 self.save_state() 실행됩니다.
                => 초기에 __init__에서 self_best_score / self.history를 만들었고 이를 넣습니다.
                => "quizzes": [quiz.to_dict() for quiz in self.quizzes]
                => 리스트 컴프레헨션을 사용하는 것입니다. [표현식 for element in 반복가능한객체]
            6-3. quiz_to_dict()은 Quiz 객체를 바로 json에 넣을 수 없으니 정제하는 함수입니다.
            6-4. 그 이후에 open을 통해 파일 객체를 만들고 dump을 통해 json 파일에 저장합니다.
