1. 튜플
    => 여러 개의 값을 하나로 묶어서 저장하는 자료형입니다.
    => 한 번 만들면 내용을 변경할 수 없는 자료형입니다. -> immutable

2. 튜플 정의
    => 중괄호를 사용해서 튜플을 정의합니다.
    => 또는 그냥 생략하고 ,만 사용해도 됩니다.
    person = ("호워자", 20, True)
    person = "호워자", 20, True

3. 튜플 사용
    3-1. 인덱스로 접근할 수 있습니다.
        => person[0] -> "호워자"
    3-2. 길이를 구할 수 있습니다.
        => printf(len(person)) -> 3

4. 튜플을 변경하려고 하면 TypeError 발생합니다.

5. 파이썬에서 함수가 여러 값을 반환하는 하는 것은 튜플로 묶어서 보내는 것입니다.

6. 튜플은 언패킹이라는 개념으로 여러 변수에 나눠 담을 수 있습니다.
    => result = (13, 7)
    => x, y = result
    => print(x) // 13
    => print(y) // 7
