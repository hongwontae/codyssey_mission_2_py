1. 파이썬에서 다른 파일은 모듈이라고 생각

2. 클래스 가져오기
    => from 파일이름 import 클래스이름

3. 함수 가져오기
    => from 파일이름 import 함수이름

4. 여러 개 가져오기
    => from 파일이름 import 객체이름, 객체이름

5. 파일 자체를 가져오는 방법
    => import 파일이름
    => 파일이름.클래스() || 파일이름.함수() 이렇게 사용합니다.

6. alias
    => from 파일이름 import 객체이름 as 별칭
    => 별칭.객체() -> 이렇게 사용할 수 있습니다.
