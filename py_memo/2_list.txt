1. list
    => 파이썬에서 여러 개의 데이터를 한 번에 저장하는 자료형입니다.
    => 배열과 유사합니다.
    => 리스트를 논리연산자와 함께 사용했을 떄 빈 리스트는 False, 값이 있으면 True가 나옵니다.

2. list 문법
    => scores = [10, 20, 50, 70, 100]
    => 변수이름 = [data1, data2...]

3. list는 인덱스를 사용할 수 있습니다.
    => scores[1] -> 20
    => 인덱스 접근 후 수정할 수 있습니다.

4. type(scores) -> <class 'list'>

5. list의 데이터들은 같은 자료형이 아니어도 됩니다.
    => data = [10, 'h', True, 90.2]

6. list 메서드
    6-1. list.append(x) : 맨 뒤에 요소를 추가합니다.
    6-2. list.extend(iterable)
        => 이 떄 반복 가능한 객체가 들어오면 하나씩 뒤에서부터 추가됩니다. -> 문자열 가능
    6-3. insert(index, value)
        => 원하는 인덱스에 값을 추가합니다.
    6-4. remove(value)
        => value를 받아서 값을 삭제합니다.
    6-5. pop()
        => 맨 뒤에 값을 삭제하고 그 값을 반환합니다.
        => 인자를 주면 그 인덱스에 해당하는 값을 삭제합니다.
    6-6. clear()
        => 모든 요소를 삭제합니다.
    6-7. index(value)
        => value를 받아서 값의 위치를 반환합니다.
    6-8. count(value)
        => 받은 value가 얼마나 있는지 반환합니다.
        => value가 없다면 에러를 발생시킵니다.
    6-9. sort()
        => 리스트 자체를 정렬시킵니다.
        => 일반적으로는 오름차순이고 reverse=True를 주면 내림차순으로 정렬합니다
        => 문자열 길이 순서 정렬은 key=len을 줍니다.
    6-10. sorted()
        => 원본은 놔두고 복사해서 정렬 후 반환합니다.
    6-11. reverse()
        => 리스트 자체의 순서를 뒤집습니다.
    6-12. copy()
        => 얕은 복사를 실행하고 반환합니다.
