1. list
    => 파이썬에서 여러 개의 데이터를 한 번에 저장하는 자료형입니다.
    => 배열과 유사합니다.

2. list 문법
    => scores = [10, 20, 50, 70, 100]
    => 변수이름 = [data1, data2...]

3. list는 인덱스를 사용할 수 있습니다.
    => scores[1] -> 20
    => 인덱스 접근 후 수정할 수 있습니다.

4. type(scores) -> <class 'list'>

5. list의 데이터들은 같은 자료형이 아니어도 됩니다.
    => data = [10, 'h', True, 90.2]
