1. JSON
    1-1. 데이터를 저장하거나 주고받기 위한 텍스트 형식입니다.
    1-2. JSON 파일에 저장하여 프로그램이 끝나도 다시 데이터를 읽어올 수 있습니다.
    1-3. JSON은 문자열은 반드시 큰따옴표로 감싸야 합니다.
    1-4. JSON은 문자열, 숫자, boolean(true/false), null, 배열, 객체를 저장할 수 있습니다.


2. import json 
    2-1. json 데이터와 파이썬 객체 -> 서로 변환하는 역할을 합니다.
    2-2. JSON 문자열 <--> Python 객체 / JSON 파일 <- -> Python 객체
    2-3. import json를 상단에 기재해야 사용 가능합니다.

    2-4. JSON과 Python 자료형
            JSON	Python
            Object	dict
            Array	list
            String	str
            Number(int)	int
            Number(float)	float
            true	True
            false	False
            null	None

    2-5. json.load()
        => 문자열(JSON)을 Python 객체로 변환하는 메서드입니다.
        => 인자는 파일 객체를 줘야 합니다.
        => json.load()는 내부적으로 f.read()처럼 인자.read()를 호출합니다. -> 그래서 파일 객체 필요

    2-6. json.loads()
        => 인자로 json 형식 문자열을 받아서 python 객체로 변환하는 메서드입니다.

    2-7. json.dumps()
        => Python 객체를 JSON 형식의 문자열로 변환하는 함수입니다.
    
    2-8. json.dump(obj, file)
        => 첫 번쨰 인자로 파이썬 객체, 두 번쨰 인자로 파일 객체를 받습니다.
        => 파이썬 객체 -> json으로 변환 가능한 파이썬 객체입니다. dict, list, tuple, str, int..
        => 받은 파이썬 객체를 문자열로 만들고 바로 파일에 write합니다.
    2-9. dump() / dumps() 옵션
        => indent : 들여쓰기입니다. 대체로 4를 사용합니다.
        => ensure_ascii : 파일의 JSON 문자열 안에서 한글을 ASCII로 바꿔 저장할까? 말까?
