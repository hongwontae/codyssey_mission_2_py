1. dict
    => 키를 이용해서 값을 찾는 자료형입니다.
    => 파이썬은 . 접근이 불가합니다. 대괄호나 get을 사용해야 합니다.
    => 파이썬에서 .은 항상 객체의 속성으로 접근합니다.

2. 리스트는 인덱스를 통해 값을 찾고 딕셔너리는 키로 값을 찾습니다.

3. dict 문법
students = {"name" : "Hong Won Tae","age" : 20,"height" : 167.7}
변수 이름 = {key-value, key-value...}

4. dict 값 가져오기
    => students[name] -> "Hong Won Tae"
    => dict이름[키]

5. dict 값 변경하기
    => studnet[age] = 29
    => dict이름[키] = value

6. dict key-value 추가
    => student[etc] = "너무 조용함"
    => dict이름[new_key] = new_value

7. dict의 key는 해시가 가능한 객체여야 합니다.
    7-1. 딕셔너리가 빠른 이유는 key를 보고 해시함수를 통해서 고정된 숫자 하나를 만듭니다.
        => 그 숫자를 이용해서 곧바로 위치로 이동할 수 있습니다.
    7-2. list는 key가 될 수 없습니다.
        => 만약 list가 변경된다면 해시 함수화 -> 고정된 숫자가 변경됨 -> 위치 문제가 발생
    7-3. 해시가 가능한 객체 -> 값이 변할 수 있는 객체는 key가 될 수 없음
