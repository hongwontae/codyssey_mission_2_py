1. 파일 열기
    1-1. f = open("memo.txt", "mode")
    1-2. 첫 번쨰 매개변수는 열 파일 이름 / 두 번쨰 매개변수는 모드 (mode -> 읽기 모드, 쓰기 모드) 
    1-3. f에 파일 객체가 저장됩니다.
    1-4.이제 f를 통해 파일을 읽거나 쓸 수 있습니다. -> 모드에 따라

2. 파일 읽기
    2-1. f = open("memo.txt", "r")
    2-1. text = f.read()
        => 파일의 내용을 전부 문자열로 가져옵니다.
    2-2. print(f.readline)
        => 파일 내용을 한 줄씩 가져옵니다.
    2-3. lines = f.readlines() / print(lines)
        => 모든 줄이 리스트가 됩니다.
    2-4. 파일 객체 내부에서 write 기능은 불가 -> r모드로 만들어서

3. 파일 쓰기
    3-1. f = open("hello.txt", "w")
        => 쓰기모드로 파일 객체를 생성합니다.
        => 모드가 w라면 파일 객체가 만들어진 순간 기존 파일의 내용이 초기화됩니다.
    3-2. f.write("Hello Python") 
        => write 메서드를 사용
    3-3. w 모드는 기존의 내용을 전부 지워 버립니다.
    3-4. f = open("hello.txt", "a")
        => 기존의 내용을 유지하고 뒤에 추가합니다.
        => f.write("\n추가된 내용")
    3-5. 파일 객체 내부에서 read 기능은 불가 -> w, a모드로 만들어서

4. 파일 닫기
    4-1. 파일을 사용 -> f.close()로 닫는 과정 필요
    4-2. 닫은 이유
        => 저장이 완료
        => OS가 사용 중인 자원을 반환
        => 다른 프로그램이 파일을 사용 가능

5. with open
    5-1. with 블록이 끝나면 자동으로 close를 호출해줍니다.
    5-2. 코드
        with open("memo.txt", "r") as f:
            text = f.read()
        print(text)
    5-3. with open(..) as f
        => open된 file 객체 이름을 as로 f로 지을 수 있습니다.

6. 파일 모드 정리
"r"	읽기(Read)
"w"	쓰기(기존 내용 삭제 후 새로 작성)
"a"	이어쓰기(Append)
"x"	새 파일 생성(이미 있으면 오류)


7. open + encoding="utf-8"
    7-1. 운영체제는 파일을 바이트로 저장합니다.
    7-2. 글자는 EC 95 88 EB 85 95 형식의 바이트로 저장됩니다.
    7-3. 그 바이트를 어떤 규칙으로 만들 것인지 결정하는 것이 인코딩입니다.
    7-4. 만약 open,w + utf-8로 썼다면 읽을 떄도 open,r utf-8를 사용해야 합니다.


8. json.dump(ensure_ascii=False)
    8-1. Json은 원래 모든 문자를 ASCII 문자로 표현할 수 있습니다.
    8-2. 그래서 한글을 \uc548\ub155 처럼 바꿉니다.
    8-3. ensure_ascii=True라면 -> \uc548\ub155
    8-4. ensure_ascii=Fasle라면 -> 한글 그대로
    8-5. 즉, 쓸 떄 한글을 제대로 보이게 할 떄 사용한다.
