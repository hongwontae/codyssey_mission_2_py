1. 파이썬에서 객체란 무엇일까?
    1-1. 객체란 메모리 위에 존재하는 하나의 데이터와 그 데이터를 다루는 기능을 함께 가진 존재입니다.
    1-2. 파이썬에서는 메모리에 만들어지는 모든 값이 객체입니다.
    1-3. 파이썬 객체는 크게 3가지를 가집니다.
        1. 값 
        2. 타입 -> type(var)
        3. 고유한 주소 id(var) -> Cpython에서는 거의 맞는 이야기 / python 공식 문서에는 그 객체를 나타내는 고유의 정수 번호
    1-4. 즉, 파이썬에서 객체는 메모리에 생성되는 하나의 구조체(데이터 덩어리)입니다.


2. 변수나 딕셔너리의 key는 객체 자체를 저장하는게 아니라 객체를 참조하는 값을 저장합니다.
    2-1.  a=10 -> a에 10이 들어가는 것이 아닌 객체(10, int, 고유 번호)를 가리키라는 참조가 저장되어 있습니다.
        => a라는 변수는 메모리 상 어딘가 존재하는 객체를 화살표로 가리키고 있다고 생각하면 됩니다.
    2-2. 함수도 동일합니다. a = def he () : ... 
        => a에 he라는 함수 객체를 화살표로 가리킨다.
    2-3. dictionary의 key는 value 자체를 저장하는게 아니라 key가 객체를 가리킵니다.
        => 그래서 함수 객체 가리킬 수 있음


3. 파이썬에는 int만 저장하는 변수, str만 저장하는 변수, .. 가 없습니다.
    => 모든 변수는 객체에 대한 참조 하나를 저장하는 공간입니다.


4. 파이썬에서 dictionary 자체의 정보를 가진 객체가 있고 내부적으로 key를 통해 value를 참조합니다.
    => a = {"b" : "asd"}일 떄 a 변수는 dict 자체 객체를 참조하고 dict에서는 b key를 통해 asd 문자열 객체를 참조합니다.
