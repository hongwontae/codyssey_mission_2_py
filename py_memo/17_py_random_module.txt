1. random 
    1-1. random 모듈은 난수를 생성하는 표준 라이브러리입니다.
    1-2. import random


2. random 모듈 함수
    2-1. random.random() # 0.638547600201898
        => 0이상 1미만의 실수를 반환합니다.
    
    2-2.random.randint(a,b) # a <= var <= b
        => 지정한 범위에서 정수 하나를 랜덤하게 뽑아주는 함수입니다.
        => 테스트 결과 : 정수만 나오고 a,b를 모두 포함합니다.
    
    2-3. random.randrange(stop) / random.randrange(start, stop) / random.randrange(start, stop, step)
        => random.randrange(5) : 랜덤하게 하나를 뽑는데 0~4
        => random.randrange(1, 10) : 랜덤하게 하나를 뽑는데 start ~ stop-1
        => random.randrange(0, 10, 2) : 랜덤하게 하나를 뽑는데 start ~ stop-1 + step 만큼 건너뜁니다.
    
    2-4. random.choice(list)
        => 리스트 중에 하나를 선택합니다.

    2-5. random.choices(population, k=1, weights=None)
        => 중복을 허용하고 여러 개를 랜덤으로 뽑아서 리스트로 반환합니다.
        => population : 반복 가능한 객체(리스트, 문자열)
        => k : 몇 개 뽑을지
        => weights :  각 요소가 뽑힐 확률(가중치)
    
    2-6. random.sample(population, k)
        => 중복을 허용하지 않고 여러 개를 랜덤으로 뽑아서 리스트로 반환합니다.
        => population : 반복 가능한 객체 (리스트, 튜플, 문자열 등)
        => k : 뽑을 개수
        => 만약 k를 len을 넘어서 들어가면 valueError가 발생합니다.
    
    2-7. random.shuffle(리스트)
        => 원본 리스트의 순서를 랜덤하게 섞는 함수입니다.
        => 즉, 원본을 수정하고 반환값을 None으로 줍니다. (None은 아무것도 없다를 알리는 객체입니다.)
