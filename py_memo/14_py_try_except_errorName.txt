1. 예외란?
    1-1. 프로그램 실행 중 발생하는 오류를 의미합니다.
    1-2. int(input)에서 사용자가 abc라는 문자열을 입력하면 valueError가 발생합니다.
        => 아무처리도 하지 않으면 에러 메시지 후 프로그램이 종료됩니다.


2. try-except의 기본 구조
    2-1. try : 
            실행할 코드
        except :
            예외가 발생하면 실행할 코드
    2-2. except에 아무것도 기재하지 않으면 모드 에러를 잡고 except 문을 실행합니다.


3. 특정 예외만 처리하기
    3-1. except 옆에 처리하고 싶은 예외 클래스를 적습니다.
    3-2. 모든 예외 클래스의 부모는 Exception입니다. -> 모든 예외를 잡고 싶은 코드를 만들 떄 사용합니다.


4. 여러 개의 except
    4-1. try :
            실행할 코드
         except ValueError :
            실행할 코드
         except ZeroDivisionError :
            실행할 코드
    => 이렇게 연달아서 사용할 수 있습니다.


5. 예외 객체 받기
    5-1. try :
            실행할 코드
         except Exception as e :
            실행할 코드


6. else/finally
    6-1. try-except에서 예외가 발생하지 않았을 떄 try가 실행되고 나서 실행됩니다.
    6-2. try-except에서 예외 발생 여부와 관계없이 무조건 실행됩니다.


7. 여러 예외 클래스
    7-1. KeyboardInterrupt -> ctrl + c으로 프로그램을 강제로 종료했을 떄
    7-2. EOFError -> ctrl+z / ctrl+d를 눌렀을 떄 


8. 예외 전파
    8-1. 예외는 함수를 넘어 전달됩니다.
    8-2. 자식 함수에서 예외가 발생했을 떄 특정한 예외 처리가 걸리지 않으면 부모로 올라가서 찾습니다.
