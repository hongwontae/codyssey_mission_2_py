** 조건식 -> 결과가 True, False가 되는 식입니다.
** 비교연산자를 사용해서 True, False를 반환시킬 수 있습니다.
** 논리연산자를 사용해서 여러 조건을 함께 사용할 수 있습니다. -> and, or (문자열 사용)
** 숫자 0 -> False, 그 외 숫자 -> True
** 빈 문자열 -> False, 비지 않은 문자열 -> True

1. if
    => 만약 조건이 참이라면 실행하는 문입니다.
    => 조건이 False라면 실행하지 않습니다.

2. if 문법
    if 조건 :
        실행할 코드
    => 여기서 조건 뒤에 콜론과 실행할 코드는 들여쓰기(4칸)이 중요합니다.
    => 들여쓰기가 끝나는 순간 if 문 밖의 코드로 인식합니다.

3. else
    => if가 거짓이면 실행하는 문입니다.

4. else 문법
    if 조건 :
        실행할 코드
    else :
        실행할 코드
    => else도 들여쓰기가 끝나는 순간 else 문 밖의 코드로 인식합니다.

5. elif
    => 앞의 조건이 거짓이면 새로운 조건을 검사하는 문입니다.

6. elif 문법
    if 조건 :
        실행할 코드
    elif 조건 :
        실행할 코드
    elif 조건 :
        실행할 코드
    else :
        실행할 코드
    => 마찬가지로 들여쓰기가 끝나는 구간이 elif 밖 코드로 인식합니다.
