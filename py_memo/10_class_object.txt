1. 클래스
    => 데이터와 기능을 하나로 묶어 놓은 설계도입니다.

2. 클래스 문법
    class 클래스 이름 :
        내용 || pass
    => pass는 아직 내용이 없다라는 의미입니다.

3. 객체
    => 클래스가 설계도라면 실제로 사용하는 것은 객체입니다.
    => obj = 클래스() -> obj를 객체라고 부릅니다.
    => 각각의 객체는 독립적입니다.

4. 생성자
    4-1. 객체가 만들어질 때 자동으로 실행되는 함수입니다.
    4-2. 코드 + 흐름
        class Car : 
            def __init__(self) :
                self.color = "Red:
                self.speed = 0
        car = Car(); // 객체 생성 -> __init__ 자동 실행 -> color 생성, spped 생성
    4-3. self
        => 현재 만들어진 객체 자기 자신을 의미합니다.
        => car1 = Car() // car1을 만들 떄 Car의 __init__에서 self가 car1
        => car2 = Car() // car2을 만들 떄 Car의 __init__에서 self가 car2
        => 이렇게 해야 각 객체가 자신만의 데이터를 가집니다.

5. 메서드
    5-1. 클래스 안에 있는 함수를 메서드라고 합니다.
    5-2. 코드
        class Car :
            def hello (self) :
                print("Hello-World")
        car = Car();
        car.hello() // "Hello-World"
    5-3. 메서드 매개변수는 자동으로 self를 받습니다.
    5-4. 메서드가 객체 자체를 수정할 수 있습니다.
    class Car:
        def __init__(self):
            self.speed = 0
        def accelerate(self):
            self.speed += 10
    car = Car()
    car.accelerate()
    car.accelerate()
    print(car.speed) //20


6. 생성자에 값 전달하기
    => 클래스를 호출할 때 데이터를 전달하면 __init__ 함수에서 self 다음의 매개변수로 전달됩니다.

7. 클래스 변수와 인스턴스 변수
    7-1. 인스턴스 변수
        => 객체마다 따로 가지는 값입니다.
        => self를 통해 만드는 값입니다.
    7-2. 클래스 변수
        => 모든 객체가 공유하는 값입니다.
        => self를 사용하지 않으면 클래스 변수입니다.
    7-3. 객체에서나 클래스에서나 클래스 변수에 접근할 수 있습니다.
        => 다만 인스턴스 변수와 클래스 변수의 이름이 동일할 떄 객체는 인스턴스 변수를 우선합니다.
    7-4. 속성은 인스턴스 변수와 클래스 변수를 의미합니다.
